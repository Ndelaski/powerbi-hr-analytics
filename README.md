# HR Attrition Analysis Dashboard

A Power BI report analysing employee attrition across 4 key areas.

## 📊 Dashboard Pages

### Overview
KPI cards + attrition by department and job role.


### Demographics
Attrition breakdown by age, gender, education, and marital status.

### Job Factors
Impact of overtime, income, job satisfaction, and tenure on attrition.

### Risk
High-risk employee identification and pivot table by dept/role.

## 🗃️ Data Source
IBM HR Analytics Employee Attrition dataset (WA_Fn-UseC_-HR-Employee-Attrition)

## 🛠️ Tools Used
- Power BI Desktop (version 2026.05)
